## Installation Notes

### New Installations
1. Download `InstallVibe_X.X.X.0_x64.msix`
2. Install the certificate (`InstallVibe.cer`) to Trusted People store (test builds only)
3. Double-click the MSIX package to install
4. Launch InstallVibe from the Start menu

### Upgrading from Previous Version
- This release will automatically upgrade your existing installation
- All user data, guides, and progress will be preserved
- **Important**: [Any special upgrade instructions or breaking changes]

### System Requirements
- Windows 10 version 19041.0 or higher
- Windows 11 (all versions)
- .NET 7.0 Runtime (included in package)
- Minimum 4 GB RAM
- 100 MB available disk space
